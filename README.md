# GANUM

# 청년 맞춤 AI 금융 코치 (가칭)

## 0. 한 줄 정리

청년 초보 투자자의 위험감수 수준과 투자 가능 금액을 진단하고, 개인별 금융 계획을 세워주는 AI 금융 코칭 서비스.

> 현재 기획·개발 단계. 기능과 정책은 변경 가능.

---

## 1. 만든 이유

- 금융 정보와 자산 현황이 여러 앱과 자료에 흩어져 있음.
- 일반적인 금융 정보를 내 저축 여력과 위험 성향에 맞춰 보기 어려움.
- 복잡한 용어와 보고서 때문에 금융 결정을 미루거나 불안해짐.

## 2. 목적

- 금융에 관심은 있지만 용어와 위험이 어려운 대학생·사회초년생이 금융 정보를 쉽게 이해하도록 도움. (초기 검증 대상: 20대 대학생)
- 내 재정 상태와 투자 성향에 맞는 자산 배분 예시와 보고서 제공.
- 결과만 알려주지 않고 판단 근거, 손실 가능성, 가정까지 함께 보여줘서 사용자가 스스로 판단하도록 지원.

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 청년 혜택 추천 | 사용자 정보를 기반으로 적합한 청년 혜택 추천 |
| 투자 성향 진단 (MBTI 방식) | 위험감수 수준과 투자 가능 금액 진단, 성향별 포트폴리오 보고서와 조언서 제공 |
| 알림 | 실시간 금융 정보, 가격 변화에 따른 포트폴리오 비중·위험 변화 알림, 사용자 상황에 맞는 행동 가이드 제안 |
| 모의투자 | 과거 같은 시점·금액으로 다른 종목에 투자했을 경우 비교, 미래는 조건별 시나리오와 상세 설명 제공 |
| 챗봇 팝업 | 화면 항목이나 금융 용어를 팝업 챗봇에게 바로 질문 |

**조언서 구성:** 위험 요인, 매도 시점 판단 근거, 자산 배분, 유리한 점 <<미정

**시뮬레이션 안내:** 미래 시뮬레이션은 확정 예측이 아닌 가정별 결과. 투자 권유가 아닌 참고용. <<미정

## 4. 이용 방식

토큰 구독제로 운영할 계획.

- 무료: 이용 가능, 제공 토큰 적음.
- 유료: 더 많은 이용량 제공.
- 구독료, 토큰 지급량, 차감 기준은 미정.


## 6. 컨벤션 규칙

### 브랜치

| 브랜치 | 용도 |
|---|---|
| main | 배포용. 직접 push 금지 |
| dev | 개발 내용을 모으는 브랜치 |
| feat/기능명 | develop에서 따서 기능 단위로 작업 |

### 커밋 메시지

`말머리: 내용` 형태로 작성. (예: `feat: 투자 성향 진단 화면 추가`)

| 말머리 | 뜻 |
|---|---|
| feat | 새 기능 |
| fix | 버그 수정 |
| docs | 문서 수정 |
| style | 코드 모양만 수정 (기능 변화 없음) |
| refactor | 코드 구조 개선 |
| chore | 설정 등 기타 작업 |

### 작업 순서

1. develop에서 feature 브랜치 생성
2. 작업 후 Pull Request 작성
3. 팀원 1명 이상 확인 후 develop에 머지
