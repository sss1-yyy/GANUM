# 금융 서비스 규칙

돈을 다루는 화면이라 일반 앱보다 조심해야 해요.

## 숫자

1. **금액은 원 단위 정수.** `0.1 + 0.2` 같은 소수 계산을 금액에 쓰지 않아요. 비율은 표시할 때만 소수 1자리.
2. **수량·평균단가**는 서버에서 **문자열**로 와요(소수 가능). 화면에서 곱셈할 때는 `Number()` 로 바꾸되, 서버가 준 `marketValue`·`profitLoss` 가 있으면 **그 값을 우선** 써요.
3. 표시 형식은 `@/shared/lib/format` 만: `formatKRW`(1,841,000원) · `formatManWon`(40만 원) · `formatSignedPercent`(+0.4%) · `formatArrowPercent`(▲ 0.4%) · `formatDDay`.
4. `null` 은 "모름"이고 `0` 과 달라요. `null` 이면 `-` 로 표시하고 0 으로 바꾸지 않아요.
5. 화면에서 직접 계산한 값(주문 후 주식 비중 등)은 **안내용**이라는 걸 알 수 있게 쓰고, 최종 값은 서버 응답을 따라요.

## 색

- 상승 `text-positive`(빨강) · 하락 `text-negative`(파랑) · 보합 회색. **초록/빨강 반대로 쓰지 않아요.**
- 오류 메시지는 `text-danger`(상승/하락색과 달라요).

## 문구

- "수익 보장", "무조건", "추천 종목" 같은 표현 금지. 시뮬레이션·수익률 화면에는 "과거 결과를 바탕으로 한 계산이며, 앞으로의 수익을 보장하지 않아요" 를 둬요.
- AI 답변·레포트에는 근거(`sources`)와 한계(`limitations`)를 숨기지 않고 보여줘요.
- 모의투자는 항상 "가상 자금 · 실제 돈이 아니에요". **실제 자산 합계에 모의 금액을 더하지 않아요.**
- 예시 숫자·예시 뉴스는 "[예시]" 를 붙여요.

## 개인정보

- 토큰·재정정보·금액을 `localStorage`/쿠키/URL 쿼리/콘솔 로그에 남기지 않아요.
- 에러 로그에 요청 본문 전체를 찍지 않아요.
- `.env*` 는 커밋 금지(`.env.example` 만 허용).

## 날짜

- 기기 시계 대신 `meta.asOf`(`referenceDate`)로 "오늘"을 정해요. 날짜는 `YYYY-MM-DD`, 시각은 RFC3339(+09:00).
