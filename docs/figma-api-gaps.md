# Figma ↔ API 명세 불일치와 임시 결정

목데이터를 만들 때 Figma 화면과 API 명세서(v0.2)가 서로 맞지 않는 곳을 정리했어요.
**기획·디자인·백엔드가 확정해 주면 이 문서를 고치고 목데이터를 바꿉니다.** 새 불일치를 발견하면 이 파일에 한 줄 추가해 주세요.

> ⚠ 이 저장소의 화면은 Figma 를 보고 만들었지만 **픽셀 단위 대조는 하지 않았어요.** 특히 B·C·D 화면 중 일부(종목 상세, 레포트 상세, 시뮬레이션 입력, 혜택 상세, 자산 하위 화면)는 Figma 의 텍스트·배치를 참고해 단순화했어요. 담당자가 Figma 와 나란히 보며 다듬어 주세요.

## D. 명세에서 아직 정해지지 않은 것 (§12 "구현 전에 확정할 항목")

Base URL·로그인/토큰 발급, 자산 연동 제공처, 시세 제공처·갱신 주기, 진단 문항·채점, 초기 모의자금·체결가·수수료, 시뮬레이션 계산 가정, 토큰 지급·차감 기준, 알림 조건.
→ 목데이터는 임의 값을 쓰고 있어요(예: 수수료 0원, 체결가 = 현재가, 토큰 6개/레포트 3·시뮬레이션 2·질문 1).

## F. Figma 파일 대조 결과 (2026-10-27, 읽기 전용으로 확인)

- 모의투자 목록·종목 상세(SK하이닉스)·주문 화면·내 자산(연결 후)·혜택 목록 6개의 이름/금액/D-day 는 Figma 와 **일치**해요.
- 포트폴리오: Figma 총 평가금액이 10,034,002원인데 같은 값이 주문 화면에서는 "주문 가능 금액"이에요. 목은 주문 화면 기준(현금 10,034,002원)으로 만들어서 총 평가금액은 18,172,002원이에요. SK하이닉스는 포트폴리오 1주 / 종목 상세 2주로 Figma 안에서도 달라요(목은 2주).
- 레포트: 목록 카드 제목(10/8 "비상금부터 만들고 월세 지원을 신청해요" 등)과 상세 조언 제목("비상금 통장부터 만들어요")이 Figma 에서 서로 달라서 목록은 `headlines`, 상세는 `advice` 로 따로 두었어요. 상세 화면의 "분야별 맞춤 조언·선택지 비교" 와 "왜 이 조언인가요(근거 4줄)" 는 API 응답에 대응 필드가 없어요.
- 레포트 상세 구현(C): Figma 레이아웃에 API 필드를 담았어요. 금융 상태 카드=`summary`, 긴급도 타임라인=`advice`(긴급도 태그 "지금 해요/이번 주/이번 달"은 필드가 없어 생략), 분야별 칩+카드=`allocation`("[예시]" 표시), 근거 카드=`sources`, 추가로 `risks` 는 "살펴볼 점" 카드. 생활 상황 칩(만 26세·사회초년생·월세 거주), 선택지 비교(장점/주의점/이런 분께·"내게 맞아요"), 근거 4줄 값은 대응 필드가 없어 생략했어요. "AI에게 더 물어보기" 버튼은 챗봇 시트(B) 연결 전이에요.
- 사용자 정보가 화면마다 달라요: 혜택 화면 "만 21세 / 월 240만 원 / 용인", 레포트 화면 "만 26세 / 월 수입 230만 원 / 연 3,200만 원 / 금융 성향 안정추구형". 사용자 프로필 목은 혜택 화면 값(21세·240만)을 쓰고, 레포트 요약 숫자는 레포트 화면 값(수입 230만·지출 170만·부채 300만)을 그대로 써요. 확정 필요.
- 시뮬레이션: Figma 예시(SK하이닉스 8월 15일 200,000원 → 227,000원, +13.5%, 최대 낙폭 -8.0%)는 목에서 그대로 재현하지 않아요. 목은 가짜 가격 그래프로 계산하므로 숫자가 달라요. 같은 숫자가 필요하면 시뮬레이션 담당(C)이 `features/simulation/mocks/routes.ts` 에 고정 응답을 추가하세요. "뉴스/경제" 이유 카드는 API 에 없어요.
- 홈 캐릭터 일러스트, 회사 로고, 아이콘은 Figma 의 이미지 자산이라 코드에 포함하지 않았어요.
